Language profile: Korean

Korean writing guidance:
- Keep sentence endings consistent with the source tone (e.g., 합니다/해요/한다).
- Avoid overusing heavy nominalized phrases if a verb-led sentence is clearer.
- Keep 조사 usage natural and reduce awkward repetition.
- Improve breath and cadence with sentence-length variation.
- Prefer precise, concrete nouns/verbs over generic abstract wording.

Mixed-language rule:
- Preserve intentional English terms, product terms, API names, and domain jargon as-is
  unless user explicitly requests translation.
